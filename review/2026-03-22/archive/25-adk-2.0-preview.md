## Summary

> [!tip] Summary
> Well-scoped preview covering core 2.0 additions clearly with concrete workflow examples. Graph syntax and real patterns (sequential, conditional routing, error handling) are useful. Main problems: wrong prereqs declaration misleads beginners, two unexplained API changes (`output_schema=str`, new `Event` fields), three redundant decision trees, and structure that buries the "should I use this?" decision after implementation details. Fixing prereqs, explaining new semantics, and merging decision aids would significantly improve usability.
